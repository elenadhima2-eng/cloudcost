☁️ CloudCost — Monitor, Optimize, Save

A web platform for cloud cost monitoring and backup management for startups.

Tech Stack
Backend: Node.js + Express + MongoDB + JWT
Frontend: React.js + Recharts + jsPDF
Cloud: MinIO S3 + Docker
AI: Gemini AI
Installation
cd server && npm install
Create a .env file with the necessary variables
node server.js
cd client && npm install && npm start
